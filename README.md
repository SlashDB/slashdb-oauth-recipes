# SlashDB OpenID Connect Authentication Scripts

This repository contains Python scripts showcasing how one could authenticate
with a SlashDB instance using the OAuth2 protocol.

It contains examples for:
- Microsoft Entra ID
  - Service Principal — for daemons, etc.
  - Interactive — for user accounts
- Google
  - Service Account — for daemons, etc.
  - Interactive — for user accounts
- Keycloak

See the subdirectories for more information about specific Identity Providers.

For more details on Single Sign-On authentication in SlashDB, see the official
documentation:
[https://docs.slashdb.com/user-guide/security/authentication/#sso-openid-connect]
